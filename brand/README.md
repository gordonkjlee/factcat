# Factcat mascot

1024px masters of the poses the Events chart uses. The app serves 480px
copies from `packages/engine/factcat_app/static/`.

The mascot **is** Factcat. No given name. Chunky slate coat, round ochre
glasses, flat graphic. No mortar, no clothes.

| File | Chart |
|---|---|
| `waiting.jpg` | Idle, looking away |
| `waiting-blink.jpg` | Rare idle blink |
| `waiting-glance-mid.jpg` | Head turning toward the camera |
| `waiting-glance.jpg` | Looking at you |
| `empty-sniff.jpg` | Query returned no rows |
| `settled.jpg` | First frame of a running query |
| `running-reach.jpg` / `running-mid.jpg` / `running-almost.jpg` / `running-contact.jpg` | Plant/lift cycle while the warehouse job is in flight |
| `unimpressed.jpg` | Query failed |

Idle may blink or glance; it does not walk. Running may pace until rows
return. `prefers-reduced-motion` freezes on the still for that state.
Do not recolour the glasses. Do not play a jingle in the app.
